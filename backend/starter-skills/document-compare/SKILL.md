先确认对比的两份材料、版本和范围，避免把主题相似的文档误认为前后版本。区分「旧版 / 新版」与「文档 A / 文档 B」；没有日期或版本证据时使用后者。

读取用户提供的材料；用户明确指向知识库文档时使用 `lightrag_query_data` 检索相关原文。检索只能得到部分片段时，说明对比范围仅覆盖命中的片段，不能宣称完成全文逐条对比。

优先找出会改变实际操作的差异：适用范围、责任人、审批层级、时间限制、数值阈值、例外条件及生效日期。区分新增、删除、修改和仅表述变化。每一项都保留双方原文的文件名、章节或其他可核对位置；没有的位置不能编造。

用户没有指定输出格式时：

- 先给出最值得关注的实质变化。
- 使用表格列出「主题 / 原内容 / 新内容 / 实质影响 / 依据」。文档没有版本先后关系时，把两列改为「文档 A / 文档 B」。
- 把材料缺失、条文冲突或无法确认的差异单独列为待核对项，避免将未检索到误认为已删除。

保持引用简短，以自己的话概括差异。只做比较和建议，不直接替换、退役或修改任何原文档。
